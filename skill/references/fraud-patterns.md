# 骗局模式库（fraud-patterns）

判"别去"前必读。硬红旗命中任意一条 → 结论"别去"，优先于漏值计算。价值阈值用 value_hint（锚中位数，与成色无关），成色未知时红旗仍生效。模式库随 badcase 回流更新。

## 硬红旗（脚本规则 ID 对应）

| ID | 模式 | 真实案例依据 | 规则 |
|---|---|---|---|
| RF_DEPOSIT | 定金/预留费：先付钱留货，收钱消失 | 二手交易常见诈骗 | deposit > 0 |
| RF_SHIPPING | 邮费盘："免费送"但到付邮费远超实际运费，赚邮费差价 | 创业邦/淘宝百科多起曝光（闲鱼"免费送"邮费套路） | shipping_fee > max(12, 25%×公允价) |
| RF_OFFPLATFORM | 高价值物品引导加微信/QQ 脱离平台（杀猪/卖货引流前置） | 平台反诈提示共性 | offplatform 且 (公允价≥300 或 账号<30天) |
| RF_TOO_GOOD | 要价≤5%价值且高价值，**并叠加≥1个其他风险信号**（脱离平台/新号/盗图/叙事/催促/定金）：饵盘概率陡增。真免费高价值物品（无任何风险信号）不触发 | "低价引流"通用模式 | price ≤ 5%×hint 且 hint ≥ 500 且 other_risk |
| RF_FAKE_IMG | 盗图/非实拍：货不对板或无货 | 闲鱼盗图纠纷常见 | images_real == false |
| RF_STORY | 叙事盘：海关扣押/罚没/内部渠道/抵债/富二代/盲盒 | 央视/知乎曝光"富二代送iPhone"盲盒群骗局；直播间"捡漏"骗局 | story 命中关键词 |

## 软红旗（降置信度，不单独改判）

- SF_NEW_ACCOUNT：账号 <30 天；
- SF_DISTANCE：自提 >30km（经济性警示，非骗局）；
- SF_URGENT：催促立即决定/制造紧迫感；
- SF_OFFPLATFORM_LOW：低价值物品引导脱离平台。

## 已知变体（持续回流）

1. **盲盒群**："富二代/海外仓盲盒免费送"→ 进群后诱导付费抽盒（RF_STORY）；
2. **到付邮费盘**：免费小家电/安全座椅，到付 25–60 元（实际运费 8–12 元）（RF_SHIPPING）；
3. **定金留货**：热门免费家具"多人要，先付定金留给你"（RF_DEPOSIT）；
4. **引流卖货**：免费好物只是饵，加微信后推销/杀猪（RF_OFFPLATFORM）；
5. **瑕疵隐瞒**：图不符/隐瞒损坏，自提现场才发现（RF_FAKE_IMG + 验货清单兜底）；
6. **拍卖托儿**（古玩/拍卖场景）：抬价叙事，本 Skill 不介入拍卖出价。

## 自提安全清单（写进每次"值得去拿"的输出）

公共场所交易、不独自入户、大件带人同行、先验货后搬运、不预付任何费用、位置只给到小区/地标级、夜间自提提示。
