# 估值锚与经验阈值（valuation-anchors）

**所有数字是经验值，须用自有案例校准**（沿用 marketing-skills-cn 原则）。改动须同步 scripts/jianlou.py 并跑评测门禁。

## 价格锚优先级

1. 近期成交锚（sold）：同型号二手近期实际成交区间，最可信；
2. 二手行情锚（used）：平台在售区间中位数；
3. 全新锚（new）：官方/电商全新价 × **0.60** 折算二手公允（经验系数，品类差异大，3C 偏保值可上调、家具偏贬值可下调）。

每个锚必须带 **来源 + 日期**，否则无效；无有效锚 → 拒答"无法评估"。

## 成色系数（相对二手行情锚）

| 成色 | 系数 |
|---|---|
| 全新（未拆封） | 1.10 |
| 几乎全新 | 1.00 |
| 轻微使用痕迹 | 0.85 |
| 明显使用痕迹 | 0.65 |
| 故障/配件机 | 0.30 |
| 未知 | 拒答 |

## 修正项

- 配件缺项：每项 −3%，封顶 −15%（充电器/遥控器/原盒/说明书按品类重要性可人工加权）；
- 明示瑕疵：每处 −8%，封顶 −30%；
- 保修剩余：每月 +0.5%，封顶 +6%。

## 成本项（自提经济账）

- 搬运基价：easy 0 / medium 30 / hard 80 元（打车/搬运经验值）；
- 距离：10km 内不计，超出 2 元/km，交通封顶 150 元；
- 时间机会成本：15 元/次（经验值）。

## 分级阈值

- 净漏值率 ≥ **25%** 且无硬红旗、置信度非 low → **值得去拿**；
- **10%–25%** → **观望**（可议价）；
- < 10% → **放弃**（无漏）；
- 硬红旗 → **别去**；锚缺失/成色未知 → **无法评估**。

## 品类提示

- 3C 数码：保值率高，重点防 RF_TOO_GOOD/RF_FAKE_IMG（骗局重灾区），序列号/购买凭证必验；
- 家具：贬值快、搬运成本主导，距离 >15km 的免费家具经常"负漏值"；
- 家电：卫生/拆装成本（空调拆机费另计，输入时并入 price 或 defects）；
- 母婴：安全件（安全座椅/婴儿床）查召回与使用年限，过期座椅直接"放弃"；
- 图书/服饰：低值高频，邮费盘重灾区（RF_SHIPPING）。
