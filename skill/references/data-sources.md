# 数据源分级与合规边界（data-sources）

Skill 只碰绿区；黄区走官方通道；红区一律不做（外部连接器除外，风险隔离）。

## 绿区（主通道）

| 源 | 接入 | 说明 |
|---|---|---|
| 用户喂数据 | 截图/链接/转发文本 | 闲鱼、微信群、朋友圈截图 → 宿主视觉读图；**国内最密供给在封闭微信群，靠用户手动转发** |
| 豆瓣同城/极简生活小组 | 公开页低频只读 | 搜索+浏览公开帖，尊重 robots 与频率 |
| 本地公众号/社区论坛 | 宿主搜索 | 公开文章 |
| 海外公开源 | Craigslist free 区 / Freecycle / Trash Nothing 公开帖 | 海外主通道，原始爆款案例吃的就是这波 |

## 黄区（官方通道优先）

- 什么值得买"免费送/白菜价"爆料：公开页/RSS 低频；开放平台 API 需申请 appkey；
- 品牌官网/官方翻新页：公开页低频。

## 红区（Skill 本体不做）

- 闲鱼站内批量抓取/模拟登录、微信群爬取、绕过风控；
- 可选外部连接器：用户**自愿自部署**第三方监控器（如 ai-goofish-monitor），Skill 只消费其输出 JSON 做判断；风险（封号/违反平台协议/法律边界）由部署者自担，文档须披露。

## 巡检频率建议

公开源每小时级（宿主 automation），单源单次 ≤10 页；不做分钟级承诺。简报定位"每日精选 + 高价值提醒"。
