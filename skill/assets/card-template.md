# 捡漏卡片输出模板

```
【结论】值得去拿 / 观望 / 放弃 / 别去 / 无法评估（置信度：高/中/低）
【标的】物品 · 成色 · 位置/距离 · 自提难度 · 要价(免费/低价)
【价格锚】二手行情 ¥X–Y（来源, 日期）｜成交锚 ¥Z（来源, 日期）
【估值】公允价 ¥F（成色/配件/瑕疵/保修修正明细）
【总成本】要价 + 邮费 + 定金 + 搬运交通 + 时间 = ¥C
【净漏值】+N%（= (F−C)/F）
【红旗】硬 0 条 / 软 N 条（逐条列 ID 与证据）
【行动】联系话术 / 议价区间 / 需对方补充的证据（实拍、凭证、尺寸）/ 自提安全清单
【免责声明】估值仅供参考，交易自行决策；永不代付。
```

规则：结论先行；每个锚带来源+日期；"别去"必须列出命中的硬红旗；"无法评估"必须说明缺什么。
